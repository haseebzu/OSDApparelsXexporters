# Clothing Size Grading and Size Charts for Brands

A size chart explains the intended measurements for each size. Grading is the controlled set of changes used to move those measurements across a size range. Brands get better results when they provide a clear base size, measurement points and fit intent before sampling, then review the fit sample against the same written record.

## Define the base garment

Start with the product type, intended wearer, fit direction and base size. State whether the fit is regular, relaxed, oversized, cropped or another defined direction. Add a technical sketch or reference image, but keep the written measurements as the approval reference.

List each point of measure that matters to the garment. A T-shirt may need body length, chest width, shoulder width, sleeve length and neck opening. A hoodie may also need hood dimensions, rib measurements and pocket placement. Use consistent names and units throughout the brief.

## Separate a size chart from a fit opinion

A comment such as “make it more relaxed” is useful context but does not tell a production team how the garment should change. Pair it with the relevant measurement instruction or a revised size chart. When reviewing a sample, record the observed measurement, the target measurement and the approved adjustment.

Fit should also be reviewed in the intended fabric. Material weight, stretch and construction can change how the same measurements feel on the body. If the fabric direction changes, revisit the fit review rather than assuming the previous approval still applies.

## Build grading decisions into the brief

Grading should follow the brand's intended size range, not a copied chart from an unrelated product. Explain which sizes are needed and whether the range differs by product or market. If a brand is still deciding its range, use sampling and fit review to settle the base specification before seeking broad production approval.

Do not claim that a standard grading rule suits every collection. The appropriate changes depend on garment type, fit, fabric and intended customer. OSD can review the buyer's supplied product, quantity, fabric and fit requirements as part of the quotation process.

## Keep an approval trail

Name each size-chart version and identify which one was used for a sample. Record adjustments after fit review, then circulate one current version. This avoids a common problem: artwork, sample comments and the quotation referring to different garment revisions.

## Questions brands often ask

### Can I use a competitor garment as a reference?

A reference can help explain the desired fit, but provide your own measurements and design requirements rather than relying only on another product.

### Do I need a tech pack?

A tech pack is useful, but a structured measurement table, reference images and written construction notes can also help establish a first discussion. Confirm what is needed for the specific product in the quote.

### When should sizes be finalised?

Finalise the approved size chart before bulk production is confirmed. Changes made later may affect the commercial review.
